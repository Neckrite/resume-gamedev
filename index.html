О себе

Студент 4 курса факультета информационных технологий Полоцкого государственного университета (группа 23-СТ). Специализируюсь на разработке игр: пишу геймплей на C# под Unity 6, самостоятельно создаю 3D-модели и звук — от модели мельницы в Blender до саундтрека в FL Studio.

Помимо Unity, пишу полноценные игры на чистом JavaScript (HTML5 Canvas, Web Audio API) — без движка и внешних библиотек.

Есть опыт автоматизации сборки Unity-проектов через CLI (headless-сборка WebGL), работы с Git по веточной модели с Pull Request и код-ревью.

Проекты

«Ветряная долина» — интерактивная 3D-сцена

Unity 6 (URP) · C# · Blender — учебный проект, 2026
  • Полный цикл производства: модели мельницы, ландшафта и птиц созданы в Blender и импортированы в движок.
  • Цикл «день/ночь»: вращение солнца и луны, динамическое освещение и анимация параметров скайбокса (цвет, атмосферность).
  • Система птиц: спавнер со случайными интервалами и маршрутами на корутинах, полёт по вейпоинтам с плавным доворотом (Quaternion.Slerp).
  • Интерактивная мельница: при нажатии E в триггер-зоне лопасти плавно замедляются и возвращаются к обычной скорости (Animator, MoveTowards).
  • Камера от первого лица: CharacterController, движение и обзор мышью, гравитация.

«Стрелочный Лабиринт — Созвездия» (Arrow Maze)

HTML5 Canvas · Vanilla JS · Web Audio API — личный проект, 2026 · играть онлайн
  • Полноценная игра-головоломка в одном HTML-файле (~4 400 строк, без движка и библиотек): поле заполнено «змейками»-стрелками, каждая скользит по своему направлению — цель выпустить их за край поля.
  • Процедурная генерация уровней (15×15 / 18×18 / 20×20) со встроенным солвером: каждый уровень гарантированно решаем.
  • Игровая экономика: монеты, самоцветы, магазин, заклинания, 4 сердца, таймер, 12+ достижений с прогрессом, карта прогрессии «Созвездия».
  • 10 тем оформления на CSS Custom Properties и анимированные canvas-фоны (звёздное небо, лава, неон).
  • Саундтрек и SFX синтезируются в реальном времени на Web Audio API — без аудиофайлов; сохранения в localStorage.

Автоматизация сборки 2D-игры (CLI / CI)

Unity · C# · Git — лабораторный проект АРПО, 2026
  • Editor-скрипт BuildManager.cs: программная сборка WebGL через BuildPipeline.BuildPlayer() с проверкой сцен, обработкой ошибок и кодами возврата.
  • Headless-сборка из терминала: Unity -batchmode -nographics -executeMethod (успешная сборка ~11 сек, 17.2 МБ) с разбором логов.
  • Git-флоу: ветки main / LR1, осмысленные коммиты, Pull Request с ревью и слиянием.

Звук для игр: рингтон и игровой саундтрек

Audacity · FL Studio — дисциплина «Создание и обработка звука», 2026
