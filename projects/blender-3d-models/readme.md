# 3D-ассеты для игры (Blender → Unity)

Модели, созданные в Blender для проекта «Ветряная долина», плюс отчёты по лабораторным работам
дисциплины «Трёхмерное моделирование».

## Содержимое

| Файл | Что это |
|---|---|
| `Windmill.blend` / `Windmill.fbx` | Ветряк — исходник и экспорт для Unity |
| `Landscape.blend` / `Landscape.fbx` | Ландшафт (поле) — исходник и экспорт |
| `Bird.blend` / `Bird.fbx` | Птица — исходник и экспорт |
| `texture/` | Текстуры (grass, rock и др.) |
| `exports-obj/` | Экспорт в OBJ/MTL (Ветряк, птичка) |
| `lab1.docx` | Отчёт ЛР №1 «Основы Blender — моделирование и сцена» |
| `lab2.docx` | Отчёт ЛР №2 «UV-развертка, текстурирование» |

## Что сделано

- **Моделирование**: ветряк, ландшафт и птица построены с нуля в Blender.
- **UV-развёртка**: швы размечены логически (Mark Seam), острова без перекрытий в диапазоне [0,1],
  проверка шахматной текстурой (Checker Texture).
- **PBR-материалы**: Principled BSDF, настройка Base Color и Roughness под тип поверхности,
  осмысленные имена материалов.
- **Экспорт в движок**: FBX для Unity-проекта, OBJ/MTL как универсальный формат.

Экспорт текстур: папка `texture/` используется и в Blender-сценах, и в Unity-материалах.
