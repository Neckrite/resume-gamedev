# «Ветряная долина» — интерактивная 3D-сцена (Unity 6)

Учебный проект по дисциплине «Трёхмерное моделирование» (вариант 46): поле с ветряками,
которые можно замедлить, пролетающими птицами и полным циклом день/ночь.

**Движок:** Unity 6000.4.8f1 (URP) · **Язык:** C#

## Как открыть

1. Установить Unity 6000.4.8f1 (модуль Windows/Mac).
2. Unity Hub → Add → выбрать эту папку (`vetryanaya-dolina-unity`).
3. Открыть сцену `Assets/Scenes/SampleScene.unity`.

## Управление

- **Мышь** — обзор, **WASD** — передвижение (контроллер от первого лица).
- **E** внутри зоны у ветряка — лопасти плавно замедляются, затем возвращаются к обычной скорости.

## Структура

| Путь | Содержимое |
|---|---|
| `Assets/Scripts/` | Весь код: `PlayerController`, `DayNightCycle`, `BirdSpawner`, `BirdFlight`, `WindmillController` |
| `Assets/Models/` | Импортированные модели (Windmill, Landscape, Bird) |
| `Assets/Animations/`, `Assets/Prefabs/`, `Assets/Materials/`, `Assets/Textures/` | Анимации мельницы, префабы птиц, материалы и текстуры |
| `Assets/Scenes/SampleScene.unity` | Основная сцена |

## Что реализовано в коде

- `PlayerController.cs` — камера от первого лица: `CharacterController`, движение WASD,
  обзор мышью с ограничением угла, гравитация, блокировка курсора.
- `DayNightCycle.cs` — вращение солнца и луны по кругу, плавное перераспределение интенсивности
  и цвета света, динамическая настройка параметров скайбокса (`_SkyTint`, `_GroundColor`,
  `_AtmosphereThickness`) с восстановлением при выключении.
- `BirdSpawner.cs` — корутина со случайными интервалами спавна (10–30 с), выбор случайного
  маршрута из настраиваемых, спавн 1–2 птиц с задержкой.
- `BirdFlight.cs` — полёт по вейпоинтам (`Vector3.MoveTowards`) с плавным доворотом
  (`Quaternion.Slerp`) и уничтожением в конце маршрута.
- `WindmillController.cs` — триггер-зона вокруг ветряка: нажатие `E` плавно снижает
  скорость аниматора (`Animator.speed`, `MoveTowards`), через 3 секунды скорость возвращается.

Исходники моделей (Blender + FBX) лежат в соседней папке [blender-3d-models](../blender-3d-models/).
