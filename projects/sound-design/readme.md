# Звук для игр (СИОЗ: Audacity + FL Studio)

Лабораторные работы по дисциплине «Создание и обработка звука»: постобработка, мастеринг,
MIDI/DAW и сведение саундтрека для игры.

## lab5-audacity-basics — создание и постобработка (Audacity)

| Файл | Что это |
|---|---|
| `сиоз5.docx` | Отчёт ЛР №5 |
| `Исходный.wav` / `Исходный.mp3` | Исходная голосовая запись (WAV 44.1 кГц / MP3) |
| `базовые.mp3` | Базовые эффекты: коррекция шипящих, мягкое ограничение |
| `специальный.mp3` | Специальный эффект: эхо |
| `Базовое5лаба.aup3` | Проект Audacity |

## lab6-audacity-mastering — мастеринг (Audacity)

| Файл | Что это |
|---|---|
| `сиоз6.docx` | Отчёт ЛР №6 |
| `рингтон_вариант8_лаба6.mp3` | Готовый рингтон |

## lab7-8-fl-studio — MIDI, VST и сведение (FL Studio)

| Файл | Что это |
