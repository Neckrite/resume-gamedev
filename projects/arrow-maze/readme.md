# Стрелочный Лабиринт — Созвездия (Arrow Maze)

Игра-головоломка на чистом HTML/CSS/JavaScript — весь движок, звук и графика в одном файле
`index.html` (исходное имя файла — ГОТОВО2.html), ~4 400 строк кода, без внешних зависимостей.

**Играть онлайн:** <https://neckrite.github.io/resume-gamedev/projects/arrow-maze/>
(или открыть `index.html` в браузере локально).

## Механика

Поле-сетка заполнено «змейками»-стрелками: каждая занимает несколько клеток и смотрит
стрелкой в свою сторону. Клик по стрелке — вся змейка скользит целиком в этом направлении,
пока не упрётся в препятствие или не выйдет за край поля. Задача — выпустить все стрелки
с поля, расчистивая дорогу (в духе Rush Hour / Unblock Me, но с извилистыми змейками).

## Что внутри

- **Процедурная генерация уровней**: «змейки» рисуются алгоритмом со случайными поворотами
  (`generateSnakePath`), а встроенный солвер `isLevelSolvable()` гарантирует, что каждый
  сгенерированный уровень решаем.
- **Три размера поля**: 15×15 (24 змейки), 18×18 (каждый 5-й уровень — сложный, 32 змейки),
  20×20 (каждый 12-й — сверхсложный, 48 змеек).
- **Экономика**: монеты и цветные самоцветы; магазин (фоны, дополнительная жизнь, супер-стрелка).
- **Заклинания**: Исцеление (+1 сердце), Прилив времени (+5 секунд), активация супер-стрелки.
- **Система жизней** (4 сердца), таймер с лимитом времени на уровень, особая «золотая» стрелка,
  ворота-препятствия.
- **Достижения** (12+) с накопляемым прогрессом и наградами.
- **Прогрессия «Созвездия»** — карта прогресса игрока.
- **10 тем оформления** (Классическая, Тёмная, Лесная, Океан, Закат, Мятная, Космос, Неон,
  Лава, Персик) на CSS Custom Properties, покупаемые фоны.
- **Анимированные фоны на canvas**: звёздное небо с падающими звёздами и молниями, лава
  с частицами, неон, персики — отдельные render-циклы на `requestAnimationFrame`.
- **Процедурный саундтрек и SFX на Web Audio API**: аккордовая прогрессия C–G–Am–F с басом
  синтезируется в реальном времени, плюс звуки кликов, победы и тиков таймера — без единого
  аудиофайла в проекте.
- **Сохранения в localStorage**: прогресс, монеты, самоцветы, темы, достижения, созвездия.

## Технологии

HTML5 Canvas · Vanilla JavaScript · CSS Custom Properties · Web Audio API ·
localStorage · requestAnimationFrame
