## Проекты

### «Ветряная долина» — интерактивная 3D-сцена
*Unity 6 (URP) · C# · Blender — 2026*

- **Полный цикл производства:** модели мельницы, ландшафта и птиц созданы в Blender и импортированы в движок.
- **Цикл «день/ночь»:** вращение солнца и луны, динамическое освещение и анимация параметров скайбокса (цвет неба, атмосферность).
- **Система птиц:** спавнер со случайными интервалами и маршрутами на корутинах, полёт по вейпоинтам с плавным доворотом (`Quaternion.Slerp`).
- **Интерактивная мельница:** при нажатии `E` в триггер-зоне лопасти плавно замедляются и возвращаются к обычной скорости (Animator, `MoveTowards`).
- **Камера от первого лица:** `CharacterController`, движение и обзор мышью, гравитация.

### «Стрелочный Лабиринт — Созвездия» (Arrow Maze) — веб-головоломка
*HTML5 Canvas · Vanilla JS · Web Audio API — [играть онлайн](https://neckrite.github.io/resume-gamedev/projects/arrow-maze/)*

- **Полноценная игра-головоломка в одном HTML-файле** (~4 400 строк кода, без движка и библиотек): поле заполнено «змейками»-стрелками, каждая скользит по своему направлению — цель выпустить их за край поля.
- **Процедурная генерация уровней** (поля 15×15 / 18×18 / 20×20) со встроенным солвером: каждый сгенерированный уровень гарантированно решаем.
- **Игровая экономика:** монеты и самоцветы, магазин (фоны, жизни, супер-стрелка), заклинания, система жизней и таймер, 12+ достижений с прогрессом, карта прогрессии «Созвездия».
- **10 тем оформления** на CSS Custom Properties и анимированные canvas-фоны (звёздное небо с падающими звёздами, лава с частицами, неон).
- **Саундтрек и SFX синтезируются в реальном времени** на Web Audio API (аккорды C–G–Am–F с басом) — без единого аудиофайла; сохранения прогресса в localStorage.

### Автоматизация сборки 2D-игры (CLI / CI)
*Unity · C# · Git — дисциплина АРПО, 2026*

- **Editor-скрипт `BuildManager.cs`:** программная сборка WebGL через `BuildPipeline.BuildPlayer()` с проверкой сцен, обработкой ошибок и кодами возврата.
- **Headless-сборка из терминала:** `Unity -batchmode -nographics -executeMethod` (успешная сборка ~11 сек, 17.2 МБ) с разбором логов.
- **Git-флоу:** ветки `main` / `LR1`, осмысленные коммиты, Pull Request с ревью и слиянием.

### Звук для игр: рингтон и игровой саундтрек
*Audacity · FL Studio — дисциплина «Создание и обработка звука», 2026*

- **Рингтон в Audacity:** двухтрековый проект, мастеринг (компрессор, эквализация, реверберация), экспорт в MP3/AAC.
- **Саундтрек для игры в FL Studio:** MIDI-мелодия, VST-инструменты, сведение и мастеринг (Hardcore, Fruity Limiter).
- **Постобработка записей:** коррекция шипящих, эхо, анализ осциллограммы и спектрограммы, форматы WAV/MP3.
